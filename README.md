Has your boss ever made you do a form of users data to make querys to a DB?
or to get and set personal info from GET and POST? geez!
have you ever made so much verbose variables that your code starts to look silly 
and you can't focus well? then PersonJ is for you.

PersonJ is a framework from Java that allows you to fill a form  of user data
without you having to make every variable in the scoop, you have lots of topics
you can use and just set the variables and use them to any purpose you want
and if they are not enought, well, just add more cause the PersonJ is very
flexible.

No weird things, no Maven, no configurations. just download and use it in the default package
or add your package to the first line of PersonJ, very simple and you can easily do it.

You might be thinking: 'Is this worth it? I could just write the variables myself.' Sure — but with
PersonJ, everything is already clean, reusable, and ready to go.
just plug-and-play. if it saves you 1h or 2h of work and headaches it is already worth it.

download PersonJ, set the forms, use the forms. easy, simple, fast. PersonJ is for you.
